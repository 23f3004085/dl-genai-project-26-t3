## Project Overview

This project focuses on detecting and segmenting defects on industrial surfaces using deep learning techniques. The objective is to identify different types of surface defects from images and generate segmentation masks for the detected regions.

The project explores model development, training, evaluation, post-processing, test-time augmentation, and ensemble-based inference.
